# Study-Material-Grounded Exercise Generation and Practice Application

## My interpretation of the brief
The goal of this project is to develop an application that ingests textual study material, generates multiple-choice and short-answer questions via an LLM grounded strictly in source excerpts, and manages a verified exercise bank. The application ensures questions remain verifiable against their source material, supports deterministic evaluation for multiple-choice items alongside criteria-based AI evaluation for short answers, and handles question invalidation when source texts change.

## Why I am a good fit for this project
I am interested in applied AI engineering, specifically building reliable RAG-oriented pipelines that mitigate hallucinations. Connecting unstructured educational texts with structured question banks requires careful prompt engineering, schema validation, and robust state management. This project allows me to demonstrate reliable full-stack development and rigorous evaluation.

## Relevant experience and background
I have experience developing web applications, working with REST APIs, handling document parsing, and integrating modern LLM APIs. I understand structured output validation (e.g., JSON schemas) and building user interfaces that keep human oversight at the center of AI workflows.

## Proposed approach
I will build a modular architecture consisting of a Python backend (FastAPI) for document parsing, chunking, and LLM orchestration, paired with a modern web interface. The LLM pipeline will use schema-constrained outputs to generate questions tied to explicit text citations. I will implement deterministic scoring for multiple-choice questions, structured prompt-based grading for short answers, and a dependency tracker that flags affected questions whenever source material is updated.

## Initial plan
Define the data schemas for study units, grounded questions, references, and user attempts.

Build the document processing pipeline and implement excerpt-grounded exercise generation.

Implement JSON schema enforcement and the human-in-the-loop review interface for the question bank.

Implement the deterministic and AI-assisted grading modules with verifiable feedback.

Implement the source-change dependency invalidation logic.

Conduct comparative evaluations measuring reference correctness, latency, and assembly reproducibility.
