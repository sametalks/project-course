# Design and Performance Optimization of a Relational Database for an Electric Vehicle Charging Network with AI Support

## My interpretation of the brief
The project requires designing and implementing a 3NF relational database for an electric vehicle charging network, followed by empirical, measurement-based query optimization. The system models stations, charging points, sessions, energy consumption, tariffs, and technical events with at least one hundred thousand charging sessions and over one million measurement records. The core focus is analyzing execution plans, applying indexing strategies (such as composite or specialized indexes), and systematically benchmarking native performance against AI-suggested optimization strategies.

## Why I am a good fit for this project
I have a solid foundation in relational database management, data modeling, and performance evaluation. I am comfortable working with database-side logic and writing structured SQL queries. Comparing manual DBA indexing strategies against LLM-suggested query rewrites provides a structured, reproducible engineering challenge that fits my analytical background.

## Relevant experience and background
I have hands-on experience designing relational schemas, writing complex SQL queries involving multi-table joins, aggregations, and subqueries, as well as working with Dockerized database environments (such as Oracle Database). I am familiar with scripting automated test data generation and analyzing query execution metrics.

## Proposed approach
I will design a normalized relational schema (at least 3NF) enforcing strict constraints and foreign keys. I will deploy Oracle Database in a reproducible containerized environment and write automated data-generation scripts in Python to populate the required volume of sessions and telemetry. I will define at least ten realistic, complex business queries, profile them using EXPLAIN PLAN and DBMS_XPLAN, apply targeted indexing, and contrast the measured speedups against suggestions obtained from an external AI service.

## Initial plan
Define the relational schema, entity relationships, constraints, and business rules in 3NF.

Set up the containerized database environment and write reproducible test data generation scripts.

Formulate ten complex analytical queries (joins, window functions, time-interval aggregations).

Profile initial query performance, recording baseline runtimes and execution plans.

Apply composite and specialized indexes and benchmark execution plan modifications.

Feed slow query profiles to an AI service, evaluate its optimization suggestions empirically, and document comparative results.

## Additional information
All DDL, DML scripts, and measurement automation tools will be maintained in a Git repository. No database credentials or proprietary connection strings will be committed.
